# Project: v-JianzhangDong_25_12_16_case1

This repository contains a small Python service that demonstrates a simple
configuration-driven startup flow.  The service is intentionally minimal to
illustrate how to load settings, require environment variables, and run tests.

## 📦 Requirements

- Python 3.8+ (recommended: use a virtual environment)
- `pyyaml` (declared in `requirements.txt`)

## 🔧 Setup

You should run the project inside an isolated virtual environment.  The
instructions below will create a clean environment in the project's root
(`.venv/`) and install the required dependencies.

### 1. Create a virtual environment

```powershell
# Remove any existing environment (if present)
Remove-Item -Recurse -Force .venv

# Create a fresh environment
python -m venv .venv
```

### 2. Activate and install dependencies

```powershell
# Activate (PowerShell)
. .venv\Scripts\Activate.ps1

# Install deps
pip install -r requirements.txt
```

> ⚠️ Do not reuse an existing environment. The steps above will delete any
> existing `.venv/` and create a new one.

## ⚙️ Configuration

- **settings.yaml** — provides the service configuration (currently just the port)
- **APP_MODE** environment variable — must be set to `production` before
  running. This is required by `app.py` and will raise an error if not set or
  if the value is not `production`.

Example on PowerShell:

```powershell
$env:APP_MODE = 'production'
python app.py
```

## ▶️ Running the service

```powershell
python app.py
```

When the configuration is valid you should see:
```
Service started successfully
Port: 9123
```

## 🧪 Tests (using the `tests/` folder)

The repository includes test scripts under `tests/` that expect the app to
start successfully. Run the tests using the environment you created above:

```powershell
# Ensure the virtual environment is active
python -m pytest -q tests
```

(or run each test script directly via `python tests/case_1.py` etc.)

## 🛠️ `auto_test.py` script

A convenience script `auto_test.py` is provided (generated by the CI fix) to
start the project and run all tests inside the `tests/` directory, writing the
results to `logs/test_run.log`. See the generated `auto_test.py` file and
`logs/` for details.
